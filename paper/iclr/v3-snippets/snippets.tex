Reconstruction of a clean cube does not show how a model behaves when its
\emph{input} is corrupted, which is the situation PRISM is meant for. A latent
diffusion purifier does not start from pure noise: following the SDEdit
pattern~\citep{meng2022sdedit}, it encodes the corrupted observation, partially
diffuses and denoises that code, and decodes the result. Its first step
therefore relies on the autoencoder mapping a corrupted cube to a code close to
that of the clean cube; the closer it lands, the fewer diffusion steps are needed
and the less the diffusion model can hallucinate. We measure exactly this
encode--decode path (Table~4): Gaussian noise with standard deviation $\sigma$
times each band's own signal standard deviation is added to the input, so that
$\sigma$ is a per-band signal-to-noise level comparable across sensors, and the
output is scored against the clean cube. A \emph{noisy input} row scores the
corrupted cube itself; a model above it removes noise rather than passing it
through.

Finally, we test recovery from the transmission dropouts described in the
introduction. A random 10\% of each patch's pixels are zeroed across all bands
at the model's input, and the reconstruction is scored against the clean cube
next to the same model's reconstruction of the unmasked cube (Table~6). None of
the models was trained on masked input, so the test measures an implicit prior
under distribution shift rather than a trained inpainting capability. The 1D
Pixelwise VAE is the control: it has no spatial context, so a zeroed pixel is
unrecoverable for it by construction, and any model that loses less than it is
drawing on its neighbours.
